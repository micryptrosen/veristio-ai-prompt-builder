AI Prompt Builder

A small browser-only composition tool: guided fields become a reusable prompt and review checklist. It does not run an AI model or generate the eventual answer.

One Action, Three Stops

Reference route, not a record of an interactive code tour.

  1. 1. Enter an idea
    index.html: #prompt-form
    Eight labeled fields capture the task and supporting ingredients.
  2. 2. Organize the ingredients
    app.js: getValues, buildPrompt, buildChecklist
    Trim values, preserve supplied text, skip blank optional sections and add output/review instructions.
  3. 3. See reusable text
    app.js: generatePrompt
    Render text safely into #prompt-output and list review items. Copy and reset are separate controls.

To Change This, Start Here

  • Input labels/options: index.html, anchors goal, tone, output-format.
  • Prompt headings/default instructions: app.js: buildPrompt. Update devpost/prd.md and verify changed output.
  • Review items: app.js: buildChecklist.
  • Clipboard fallback: app.js: selectPromptText and copyButton.addEventListener; test both successful copy and denial.
  • Layout: styles.css. Check desktop and narrow widths after edits.
  • The actual reconciliation repair: empty inline favicon in index.html prevents an unnecessary favicon 404 request.

A Practice to Reuse

Connect a real owner decision to an observable result. Here, devpost/prd.md: Acceptance Criteria requires supplied ingredients to survive generation. buildPrompt implements that; devpost/verification.md records checks and owner usefulness feedback. These do not establish better downstream AI answers. On another project, keep the same decision-to-check trail and state what it cannot establish.

Run and Return

The app supports opening index.html directly. For the reviewed HTTP workflow, from the repository run python -m http.server 8404 --bind 127.0.0.1 if Python is available, then visit http://127.0.0.1:8404/. Stop the temporary server after use. This map is standalone HTML with no scripts or network dependencies.
